### A Rust server for practicing monument fights

</div>

Monument PvP is where Rust fights are won, and there's no good way to get better at it: on a normal server, every attempt costs you a kit and a wipe's worth of progress. grub.gg is a server built purely for practice. Queue up from a lobby, get a kit, run structured attack/defend scenarios at real monuments. Lose, reset, run it again.

The whole thing is being built in the open here: the game-server plugins, the website, and the infrastructure behind both.
